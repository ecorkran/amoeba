# Notes

## Overview

Notes is a small command-line tool for keeping short text notes. A user adds a note, lists their notes, shows when each was written, and moves notes in and out as files.

## Storage

All notes are stored as JSON Lines files, one note per line.

## Scope

One user, one machine, no network. Notes are plain text.
